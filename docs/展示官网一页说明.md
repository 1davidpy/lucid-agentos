# lucid-agentos 展示官网｜一页式介绍

**访问地址：** https://1davidpy.github.io/lucid-agentos/

## 一句话定位

lucid-agentos 是面向具身机器人的智能体运行系统：它把环境感知、任务理解、行动规划、空间记忆、技能执行和结果验证连接起来，让机器人不仅能“听懂指令”，还能在真实世界任务中形成“观察—思考—行动—验证”的闭环。

## 这个页面希望传达什么

传统机器人往往依赖固定流程，只能在预先设定的场景中执行单一动作。lucid-agentos 关注的是更通用的任务能力：用户可以用自然语言描述目标，系统根据机器人实时看到的环境拆解任务、选择能力、执行动作，并在环境发生变化或执行失败时重新判断。它位于基础模型与机器人控制系统之间，相当于机器人的“认知与任务操作层”。

官网按照一条完整故事线展开：

1. **理解真实环境**：融合相机、深度、激光雷达和位姿等在线信息，形成对周围环境的认识。
2. **完成长程任务**：把一句复杂指令拆分成搜索、导航、抓取、搬运、返回等连续步骤。
3. **保留空间记忆**：记住机器人到过的位置和看到的目标，为跨步骤、跨会话任务提供线索。
4. **验证任务结果**：区分“命令已发出”“机器人已到达”和“任务确实完成”，通过新的传感器证据进行确认。
5. **适配不同载体**：当前重点展示 Unitree G1、Go2 及 MuJoCo、Isaac Sim 等环境，系统设计目标是不绑定单一机器人本体。

## 60 秒推荐讲解词

> lucid-agentos 希望解决的，不是让机器人多执行一个动作，而是让它能够持续完成一个真实任务。用户只需要给出自然语言目标，系统会连接感知、推理、空间记忆和机器人技能，形成从观察环境、制定计划、执行动作到验证结果的完整闭环。页面中的演示覆盖找门、人物跟随、取水返回和跨房间搬运等多阶段任务。我们尤其强调“可验证”：系统不会把工具调用成功直接等同于任务完成，而是要求机器人停稳、到达目标，并通过新的现场观测确认结果。这为机器人从演示走向可靠应用提供了一套可追踪、可复核的系统基础。

## 对外传播可用关键词

**自然语言交互、具身智能、任务闭环、多模态感知、长程规划、空间记忆、端云协同、安全执行、结果验证、机器人无关架构。**

推荐标题示例：

- 从“听懂”到“完成”：lucid-agentos 让机器人形成任务闭环
- 让智能体进入真实世界：连接感知、推理、行动与验证
- 不只会执行，更能验证结果的具身智能系统

## 对外表述边界

- 可以说“面向多种机器人设计”“已在 G1、Go2 和仿真环境中开展适配与验证”；不宜说“已经兼容所有机器人”。
- 可以说“支持找门、跟随、取水、搬运等任务演示”；不宜把仿真演示描述为已完成规模化实机部署。
- 可以说“具备安全约束、急停和结果验证机制”；不宜称为“绝对安全”或“零失败”。
- 任务因目标未找到、风险过高或证据不足而停止，是系统的安全结果，不应包装成成功。

## 常见问题

**它是一个大模型吗？** 不是。大模型是推理能力之一，lucid-agentos 负责把模型、传感器、记忆、机器人技能和安全验证组织成可持续运行的任务系统。

**它一定要使用 G1 吗？** 不一定。G1 是当前重点适配和展示载体之一；更换机器人时，需要接入相应的传感器、运动控制和技能接口。

**官网上的视频代表什么？** 它们用于展示系统的任务流程与能力方向。对外引用时，应标明具体演示属于仿真还是真实环境，避免混淆。
